C952 Binary Practice Problems

Interactive practice on binary representation and arithmetic for Computer Architecture (C952). Click an answer to check it — you’ll get instant feedback, and you can keep trying until you get it right. Answers are shuffled each time you reload the page.

These questions are drawn from Dr. Jim Ashe’s C952 practice worksheets. Spot an error? Let me know.

from IPython.display import Javascript, display
import json
from jupyterquiz import display_quiz

# MyST renders math server-side and ships no client-side MathJax, so load one
# here (configured for $...$) and typeset once it is ready. This lets the LaTeX
# inside the dynamically-injected quiz content render.
display(Javascript('''
if (typeof MathJax === 'undefined' && !window._jqMathJax) {
  window._jqMathJax = true;
  window.MathJax = { tex: { inlineMath: [['$','$']], displayMath: [['$$','$$']] },
                     options: { skipHtmlTags: ['script','noscript','style','textarea','pre','code'] } };
  var s = document.createElement('script');
  s.src = 'https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-mml-chtml.js';
  s.async = true;
  s.onload = function () { if (window.MathJax && MathJax.typesetPromise) { MathJax.typesetPromise(); } };
  document.head.appendChild(s);
}
'''))

with open("questions_binary.json", "r", encoding="utf-8") as f:
    questions = json.load(f)

display_quiz(questions, shuffle_answers=True, max_width=800)
